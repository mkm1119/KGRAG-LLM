# 11/26 시연 구상 (메모)

랩미팅 자료(2026.11 KG 구축 how (2))의 연구 내용과 분리해 둔 시연 구상이다. 4장 검색·답변 구조를 그대로 쓰고, 랩미팅 자료 정리가 끝난 뒤 진행한다.

## 시연 방식 (11/02 녹취 확인)
- 현장에서는 참석자에게 노트북을 드리고 구현된 범위 안에서 직접 질문하게 한다. 그래서 범위 안내와 범위 밖 질문 처리가 가장 중요하다.
- 발표 흐름: 어떻게 만들었는지(PPT) → 예시 동영상 → 인터넷이 되면 참석자 직접 질문.
- 동영상은 인터넷이 안 될 때를 대비한 예시 하나.
- 같은 날 태스크 후보 목록(`lab_meeting/task_candidates/`)으로 실무자 체크를 받는다.

## 시연 구조
- 채팅 화면: 노트북 브라우저에서 질문하고 답변을 본다. 답변의 출처 번호를 누르면 원문(승인 기록 행, 별표3 원문, 측정값)이 보인다.
- 답할 수 있는 범위 안내: 대상 댐 4개와 질문 종류(CQ1~CQ6), 예시 질문을 화면에 둔다. 범위 밖 질문과 인사에는 범위와 예시 질문으로 안내한다.
- 이어지는 질문: "그럼 소양강댐은?"처럼 앞 질문의 댐·기간을 이어받는다.
- 속도: 측정 저장소를 서버를 켤 때 미리 읽어 둔다.
- 접속: 노트북 → 핫스팟 → 연구실 서버. 인터넷이 안 될 때를 대비해 시연 동영상을 찍어 둔다.
- 시연 때 밝힐 점: "현재"는 저장된 마지막 시각(2026-09-28)이며 실시간이 아니다. 범용 LLM을 썼다. 실제 운영에 쓰려면 자료 연결 확대와 에이전트 등이 더 필요하다.

## 시연 전 확인
- 질문 몇 개를 새로 만들어 서버에서 다시 답변을 받고 결과를 정리한다(랩미팅 자료 메모 #5).
- 서버 실행 기록(2026-10-16)에서 본 점: 자료에 없는 사유를 추정한 판단 문장, 출처 자리에 의도 이름([CQ5])을 적은 답변, 같은 종합 질문 5번 중 CQ2를 뽑은 것은 1번.
