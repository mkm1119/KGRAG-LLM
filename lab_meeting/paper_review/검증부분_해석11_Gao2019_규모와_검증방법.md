## 1. Gao 외 (2019)

### 풀려는 문제

- KG의 정확도 = 트리플 중 맞는 것의 비율. 맞는지는 사람이 판정한다.
- 큰 KG는 전부 판정할 수 없다. 그래서 일부를 뽑아 판정하고 전체 정확도를 추정한다.
- 목표: 정해 둔 오차 범위(예: 95% 신뢰수준에서 ±5%)를 만족하면서 **사람의 판정 시간을 최소로** 한다.

### 핵심 관찰: 판정 비용은 트리플 수에 비례하지 않는다

- 판정은 두 단계다. ① 이 대상이 무엇인지 파악(약 45초) ② 관계가 맞는지 확인(약 25초).
- 같은 대상에 딸린 트리플을 이어서 판정하면 ①을 한 번만 하면 된다.
- 그래서 트리플을 무작위로 뽑는 것보다 **대상을 먼저 뽑고, 그 대상의 트리플을 몇 개(3~5개)씩 뽑는 방식**(TWCS)이 싸다. 판정 시간이 최대 60% 줄었다.

### 결과

| 내용 | 수치 |
|---|---|
| MOVIE (트리플 200만) | 174개를 판정해 정확도 88% ± 5% 추정 |
| 필요한 표본 수와 KG 크기 | 2,600만~1억 3천만으로 키워도 비용이 거의 같음. **"KG 크기에 민감하지 않다"** |
| 비용이 가장 큰 경우 | 정확도가 50% 근처일 때. 정확도가 높을수록 적게 봐도 됨 |

### KG가 계속 늘어날 때 (우리 전제와 맞닿는 부분)

- 추가분이 들어올 때마다 처음부터 다시 평가하지 않는다. **앞서 판정한 결과를 재사용**한다.
- 방식 둘: (가) 표본 통을 유지하며 일부만 교체, (나) 추가분을 별도 묶음으로 보고 그 묶음에서만 새로 뽑음.
- (나)가 더 싸다(비용 최대 80% 절감). 다만 첫 추정이 틀렸으면 (가)가 더 빨리 바로잡는다.

### 관련 연구에서 저자들이 한 말 (8장)

- 단순 무작위 표본이 "단순하지만 널리 쓰이는 방법"이다.
- KGEval(Ojha·Talukdar 2017): 판정한 트리플의 맞고 틀림을 규칙으로 다른 트리플에 전파해 사람 수고를 줄인다. Gao의 평가: 전파가 확률적이라 **틀린 전파가 생기고 추정의 편향을 가늠하기 어렵다**. 계산이 무거워 큰 KG에 안 맞는다.
- 오류 탐지·사실 검증 연구는 "밀접하지만" 정확도 평가에 쓰인 적은 없다고 했다.

### 이 논문에 없는 것

- 규칙 검사나 원본 대조 같은 자동 검사는 다루지 않는다. 처음부터 "사람이 판정한다"를 전제로 한다.
- 술어별·유형별 정확도는 향후 과제로 남겼다.

## 2. 다른 문헌은 뭐라고 하나

### Hogan 외 (2021) 7장: 차원마다 재는 방법이 다르다

| 차원 | 재는 방법으로 든 것 |
|---|---|
| 구문 정확성 | "검증 도구로 평가할 수 있다" |
| 유효성(제약 위반 없음) | "제약별 위반 수를 센다" |
| 일관성 | "찾은 모순의 수" |
| **의미 정확성** | **"평가하기 어렵다."** 선택지 셋: ① 사람이 직접 확인 ② 여러 출처와 자동 대조 ③ **KG를 만든 과정 자체를 검증**(전문가나 정답 자료로 정밀도 측정) |
| 완전성 | 이상적인 KG를 알아야 해서 직접 재기 어렵다. 정답 표본과 비교하거나, 완전한 원본에 대한 추출 재현율을 잰다 |

### Shami 외 (2026) 서론: 세 갈래와 각각의 한계

| 방법 | 논문의 평가 |
|---|---|
| 전문가 수동 검증 | "가장 신뢰할 수 있다." 그러나 트리플 하나에 몇 분이 걸려 큰 규모에서는 불가능 |
| 규칙·제약 기반 자동 검증 | "더 확장 가능한 대안." 그러나 잘 정의되고 자주 나오는 사실에만 잘 맞고, 규칙을 사람이 정의하는 것도 어렵고 비싸다 |
| LLM | 가능성은 있으나 "실제 KG 검증에 쓸 만큼 안정적이고 신뢰할 수 있지 않다." 외부 근거를 붙여도, 여러 모델을 합의시켜도 일관되게 좋아지지 않는다 |

### Marchesin·Silvello (2025) 서론

- "큰 KG의 모든 사실을 판정하는 것은 불가능하다. 그래서 통계적 보장이 있는 표본 추정이 필요하다."
- 현재 최신 방법은 표본 추출 + 점 추정 + 구간이다. Gao의 계열이 지금도 표준이라는 뜻이다.

### Paulheim (2017)

- 평가 방식 셋: 일부를 사람이 판정한 정답, KG 자체를 기준으로 삼기, 방법이 낸 결과를 사후에 사람이 판정. 사후 판정도 "대개 표본에 대해서만" 한다.
- 결론: "확장성 문제는 현재 연구에서 드물게만 다뤄진다."

### Zaveri 외 (2016)

- 지표 69개를 정량(값을 계산할 수 있음)과 정성(사람의 판단에 달림)으로 나눴다.
- 의미 정확성의 지표로 든 것: 이상치 탐지, 속성 간 의존 관계 검사, 크라우드소싱.
- 조사한 도구 12개 중 11개가 반자동이다. 완전 자동은 1개뿐이다.

### Huaman 외 (2020) 서론

- "KG 검증은 흔히 전문가가 한다. 그러나 이 방식은 KG의 규모를 따라가지 못한다." 그래서 반자동 도구가 나왔고, 이 논문은 그 도구들의 결과가 **재현되지 않는다**는 것을 보였다(초록).

## 3. 그래서 "두 가지다"에 근거가 있나

**"문헌의 답은 두 가지"라고 정리한 문장은 어느 문헌에도 없다. 내가 묶은 것이다.** 문헌이 실제로 뒷받침하는 것은 아래다.

| 내가 한 말 | 문헌이 실제로 말한 것 | 근거 |
|---|---|---|
| 기계가 할 수 있는 것은 자동으로 | 형식·제약·일관성은 도구로 검사하고 위반 수를 센다. 규칙 기반 검증은 확장 가능하다 | Hogan 7.1.1, 7.3 / Shami 서론 |
| 사람이 필요한 것은 표본으로 | 의미 정확성은 사람 판정이 가장 믿을 만하고, 큰 규모에서는 표본으로 추정한다 | Gao 전체 / Marchesin 서론 / Shami 서론 |
| (말하지 않은 것) | 자동 사실 검증(LLM 포함)은 아직 믿기 어렵다 | Shami 초록 / Gao 8장(KGEval) / Huaman 2020 |
| (말하지 않은 것) | 의미 정확성의 셋째 길: **만든 과정을 검증한다** | Hogan 7.1.2 |

고칠 점 둘.

1. "전수"라는 말은 문헌에 없다. 문헌은 자동 검사가 "확장 가능하다"고 할 뿐이다.
2. 갈래는 둘이 아니라 **차원마다 다르다**가 정확하다. 형식·제약은 자동, 의미 정확성은 사람(규모에서는 표본) 또는 과정 검증, 자동 사실 검증은 아직 미성숙.

## 4. 우리 연구에 대어 보면 (내 정리)

| 문헌 | 우리 |
|---|---|
| 형식·제약은 자동 검사 (Hogan, Shami) | 10월에 한 규칙 검사 5개. 규모가 커져도 그대로 돌릴 수 있다 |
| 과정을 검증한다 (Hogan 7.1.2) | 우리 KG는 변환 규칙으로 만든다. 규칙이 맞으면 그 규칙이 만든 값은 규모와 무관하게 맞다. DDKG가 분류기를 전문가 정답으로 검증한 것도 이 갈래다. 11/18에 "DDKG는 KG 검증이 아니다"라고 정리했는데, Hogan의 분류로는 **의미 정확성을 평가하는 방법의 하나**다 |
| 사람 판정은 표본으로 (Gao) | 해석해서 만든 값(운영행위 68개 같은 것). 지금은 전부 볼 수 있지만 커지면 표본이 된다 |
| 늘어날 때는 추가분만 (Gao 6장) | 댐이나 기간을 추가할 때마다 추가분에서만 뽑아 판정하고 앞의 결과는 재사용 |
| LLM 판정은 아직 불안정 (Shami, Kommineni) | LLM에게 판정을 맡기는 방안은 사람 판정과 비교해 본 뒤에만 쓸 수 있다 |

**남는 빈칸.** "지금의 작은 KG에서 전부 판정해 두고, 그것을 기준으로 표본 추정이나 LLM 판정이 얼마나 맞는지 재 본다"는 생각은 읽은 범위에서 그대로 한 문헌을 찾지 못했다. 가까운 것은 Gao가 전부 판정된 NELL·YAGO로 표본 방법을 시험한 것이다(7장). 방법의 검증에 전수 판정 자료를 쓴다는 점은 같다.
