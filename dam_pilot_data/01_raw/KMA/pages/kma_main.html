새로운 서비스

고해상도 격자데이터 제공

기상관측자료에 지형효과를 반영한 3차원 객관분석 기법을 적용하여 생산한 분석자료를 제공합니다.

세계기상 관측자료 확대

전세계 170여개국 8,700여지점의 기상관측 데이터를 제공합니다.

대용량 API 서비스

API를 통한 장기간 과거 데이터 및 대용량 격자 데이터 제공을 위해 대용량 API 서비스를 제공합니다.

기상기후데이터위키

기상청 데이터를 다루는 지식과 방법을 제공합니다.
