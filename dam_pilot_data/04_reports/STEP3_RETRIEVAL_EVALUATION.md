# STEP 3 — Retrieval Evaluation (구성요소별 · 임계값 없음)

방법: 질문별로 "답하는 데 필요한 증거 종류"를 검색 전 `qa_pilot_questions.csv`에 기재하고, 검색 결과(`qa_retrieved_evidence.csv`, 총 90행)와 대조. 점수/임계값 없음.

| Q | 유형 | 필요한 증거 | 회수 여부 | 경로 | 비고 |
|---|---|---|---|---|---|
| Q01 | 직접 | Dam→Approval | 완전(4/4건 원본과 일치) | KG 1홉 | 단일 표 필터로도 가능 |
| Q02 | 직접 | Criterion→Document | 완전 | KG 1홉 | 문서 시행일 포함 |
| Q03 | 직접 | Approval 속성 | 완전 | KG 속성 | - |
| Q04 | 직접 | Dam→Station | 완전(집계) | KG 1홉 | 연관은 조회 목록 기준 |
| Q05 | 직접 | Operation | **없음(UNAVAILABLE)** | - | Operation 엔티티 0 |
| Q06 | 직접 | 당시 시점 Criterion | 현행만 회수, 당시 버전 없음 | KG 1홉 | DATA_REQUIRED |
| N01 | 자연 | Approval + 측정 창 | 부분: 승인·측정 각각 회수, 둘의 연결은 KG 아님(crosswalk 외부 조회) | KG + 파일 | S2-01 |
| N02 | 자연 | Approval→Criterion 근거 | Approval·현행 Criterion 각각만 회수; 연결 없음 | KG | 관계 부재 |
| N03 | 자연 | 광동댐 시설 Criterion | 회수 결과 0건(확인된 부재) | KG 필터 | - |
| N04 | 자연 | 승인량 vs 실제 방류 | 두 값 회수; 동일시하지 않음 | KG + 파일 | 12시간 창 |
| N05 | 자연 | 유사 사례 | 방법 없음 | - | 유사도 미정의 |

## 요약
- 직접 질문 6개 중 4개 완전 회수, 1개 부재 확인, 1개 부분(시점).
- 자연 질문 5개 중 완전 회수 0개: 필요한 증거가 **서로 다른 연결 성분**에 있어 KG 간선만으로 회수되지 않거나(N01, N02, N04), 자료·방법이 없다(N03 부재, N05).
- 재현율/정밀도 수치는 산출하지 않았다: 정답 집합을 독립적으로 구축하지 않았고 임의 임계값도 금지이므로, 본 표는 사례 수준 관찰이다.
