## Ⅳ. 세부 수행 실적

### 2. LLM 활용 데이터 파이프라인 조사

#### 2.1 수집 경로 조사

□ 수집 대상 및 경로 조사
◦ 댐 운영 판단에 필요한 자료를 수문·기상 관측자료, 운영 근거자료(법령·규정), 운영행위자료(방류승인), 내부·전력자료로 구분하여 제공기관별 수집 경로 조사 (표 2.1)
- 수문자료: K-water 물정보포털(댐별 수위·저수량·강우·유입량·방류량, 관측소별 강우·수위·유량), 한강홍수통제소·공공데이터포털 OpenAPI
- 기상자료: 기상청 ASOS 관측자료
- 운영 근거자료: 법제처 국가법령정보 공동활용(연계운영규정 등 운영규정, 연혁 포함)
- 운영행위자료: 한강홍수통제소 홍수예보 댐방류승인 이력(공공데이터포털 파일데이터)
- 내부·전력자료: 한수원 내부 운영자료, 전력단가 — 현장방문 후 확인

□ 수집 경로별 접근 조건 확인
◦ 접근 방식·인증 요건·공개 기간·갱신 주기를 비교하여 외부 공공자료 중심의 수집 가능 범위 확인
- 인증 없이 조회 가능한 경로와 서비스키(활용신청)가 필요한 경로를 구분
- 일부 기관 사이트·API는 조사 환경에서 접속이 제한되어, 해당 경로는 "확인 필요"로 분류하고 추후 확인 예정

□ 수집 구조 검토
◦ 수치자료는 별도 저장소에 보관하고 관측소 코드를 조회 키로 연계하는 방식 검토 — 방대한 시계열을 지식기반에 직접 적재하지 않고 질의 시점·대상에 맞춰 호출
◦ 자료별 갱신 주기에 따른 수집 주기 구분: 관측자료(분·시간), 운영 승인·방류 기록(수시), 규정(개정 시)

□ 내부 자료 및 전력자료
◦ 한수원 내부 센서 및 운영기록, 전력단가는 외부 조사로 확인 불가 → 현장방문 시 자료 보유 범위·접근 권한·반출 제한·연계 방식 확인 후 수집 경로 확정

#### 2.2 온톨로지·메타데이터 설계방안 조사

□ 설계 방향
◦ 온톨로지 기반 전처리 체계를 아래 절차로 설계할 계획
- 연구 대상·목적 설정 → 온톨로지가 답해야 할 질문 정의 → 용어 정리 → Class → Relation → Property 설계
◦ 수집 자료에 부착할 메타데이터 항목(대상 댐, 자료 시점, 출처, 변수, 단위, 자료 유형)을 도출하여 RAG 검색 시 필터링 기준 및 응답 시 출처·시점 제시 근거로 활용
◦ 현장방문·운영자 인터뷰에서 확인한 요구사항을 반영해 온톨로지를 단계적으로 개선(Human-in-the-loop)

### 1. 국내외 기술 트렌드 조사

#### 1.3 적용 기술요소 및 모델 제안
◦ 기술요소(지식기반 구성, 수문자료 연계, 운영자 지원체계) 도출 착수. 수치자료는 별도 저장소·문서/규정은 지식기반으로 분리 관리하고 질의 시 연계하는 방향으로 RAG-sLLM 구조 검토
