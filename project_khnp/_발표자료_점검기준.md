# 최종보고회 발표자료 점검 기준

조립: `python3.13 -I dam_pilot_data/scripts/build_final_deck.py lab_meeting/2026.11.26_한수원_발표자료_수정7.pptx <출력.pptx>`

| 구분 | 기준 |
|---|---|
| 근거 | 문장과 수치는 최종보고서 초안 또는 11/26 발표자료에 있는 것만 쓴다. 시연은 한 것과 할 것을 구분한다. |
| 문장 | 체크 줄은 내용을 말한다("~순서로 검토", "~로 정리" 같은 안내 문장 금지). 뒤에서 다룬다는 문장, 약점·변명 문장, 발주처 내부 사정은 쓰지 않는다. |
| 표기 | 수집 경로(안)에는 타 기관 이름 대신 "공개 자료". 특정 제품 이름을 정해진 것처럼 쓰지 않는다. 용어는 보고서와 같게 쓴다. |
| 한 쪽 한 내용 | 상자 머리가 그 쪽의 내용을 말한다. 체크 줄은 상자당 5개 이하, 한 줄은 두 줄 이내. 표는 8행 이하. |
| 글자 크기 | 체크 줄 13pt, 표 11pt 이상, 그림 안 글자 9pt 이상. 직접 그린 그림은 그림 파일이 아니라 도형으로 그린다. |
| 배치 | 글자 넘침·겹침이 없다. 상자 안은 글, 표, 그림으로 아래까지 채운다(체크 줄만 있는 상자는 글자를 키우고 줄 높이를 늘림, 표는 남은 높이에 맞춤). |
| 분량 | 세부 항목마다 조사한 내용(사례, 비교), 도출한 결과(안)가 모두 보이게 한다. |
| 흐름 | 조사 → 기술요소 도출 → 설계(안) → 시범 구성·시연 → 추진 방향. 표·그림 번호는 차례대로. |
