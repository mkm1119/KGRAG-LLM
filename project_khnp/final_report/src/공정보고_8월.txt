□ 주요 개념 정리
◦ RAG(검색증강생성)
- LLM이 답변을 생성하기 전에 외부 지식베이스에서 관련 정보를 검색해 답변의 사실 정확성과 관련성을 높이는 과정이다. 질의 임베딩 → 코사인 유사도 기반 검색 → 재순위화(reranking) → LLM 생성의 4단계로 구성된다 Gao, Y. et al. (2023). Retrieval-Augmented Generation for Large Language Models: A Survey. arXiv:2312.10997 — Li, J. et al., IWMS-LLM, Journal of Hydroinformatics, 27(11), 1685 (2025)에서 재인용.
. 지식베이스 구축 시점을 기준으로 사전 적재형(batch-ingested)과 실시간 API 호출형(Tool-calling)으로 구분된다.
◦ LLM / 도메인특화LLM
- 특정 과학 분야의 전문 어휘·개념·추론 과제를 다루도록 학습되거나 미세조정된 대규모 신경망 언어모델이다 Kizilkaya, D., Sermet, Y., &amp; Demir, I. (2025). Towards HydroLLM: approaches for building a domain-specific language model for hydrology. Journal of Hydroinformatics, 27(10), 1652, Glossary.
. 모델 용량과 데이터 규모의 정합(capacity-alignment)이 성능에 중요하며, 1.5B~32B 규모 비교 실험에서 8B급 모델이 가장 안정적인 성능을 보인 사례가 확인된다.
◦ 온톨로지·KG
- 온톨로지는 도메인의 형식적 어휘·스키마를 규정해 개념과 관계를 정의한 것이고, 지식그래프(KG)는 이 스키마를 실제 데이터로 채워 구체화한 것이다 Gruber, T. (1993). A Translation Approach to Portable Ontology Specifications — Li, S. et al., A Semi-Automated Framework for Flood Ontology Construction, Water, 17(19), 2801 (2025)에서 재인용·종합.
. 온톨로지는 "설계도", KG는 "채워진 그래프"에 해당한다.
◦ 온프레미스
- 클라우드·온프레미스·하이브리드 3가지 배포 방식 중 하나로, 완전한 통제와 컴플라이언스 준수가 가능하지만 상당한 초기 투자가 필요한 배포 방식이다. 헬스케어·금융·법률 등 민감한 도메인에서 주로 채택된다 Pan, G., Chodnekar, V., Roy, A., &amp; Wang, H. (2025). A Cost-Benefit Analysis of On-Premise Large Language Model Deployment: Breaking Even with Commercial LLM Services. arXiv:2509.18101.
